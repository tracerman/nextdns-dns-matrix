By protocol

DoH uses a profile URL. Keep every bootstrap IP paired with the URL from the same route. DoT uses port 853 and the TLS hostname {config-id}.dns.nextdns.io. Plain IPv4 requires Linked IP.

More platforms

Firewalla, DD-WRT, EdgeOS, BSD, Synology SRM, and firmware-specific builds can differ materially. Use the capability-based “Other router” guide or the assistant prompt below, and confirm the menu path against your firmware documentation.
